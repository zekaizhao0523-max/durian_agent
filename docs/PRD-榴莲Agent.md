# 榴莲 Agent 产品需求文档（PRD）

| 项目 | 内容 |
|------|------|
| 产品名称 | 榴莲可信选购助手（暂定） |
| 文档版本 | v1.1 |
| 更新日期 | 2026-06-10 |
| 溯源模式 | **一批一品类一码**（同一批次、同一品类共用一枚溯源码） |
| 产品形态 | 对话式 Agent + 批次溯源验真 + 自有商城成交 |

---

## 1. 产品概述

### 1.1 背景

榴莲属于高单价、高信息不对称、强情绪消费的品类。用户普遍面临「不会挑、怕买亏、不会吃、不信任渠道」等问题。团队已具备 **批次溯源码能力**（一批次内同一品类共用一码）和 **榴莲售卖业务**，具备构建「咨询 → 验真 → 购买 → 购后服务」闭环的基础。

### 1.2 产品定位

**帮用户买对、验真、吃对的榴莲私人顾问。**

区别于纯百科或纯客服：Agent 先提供专业选购建议，再基于批次溯源码建立信任，最后引导至自有商品完成成交与复购。

### 1.3 溯源模式说明

| 维度 | 说明 |
|------|------|
| 码的粒度 | **批次 + 品类**（如「2026-06-08 入库 · 猫山王 A 级」为一个码） |
| 一码覆盖范围 | 同一批次、同一品种/品类下的多颗榴莲共用同一溯源码 |
| 码的载体 | 随箱/随袋/随品类标签张贴或印刷，非每颗果独立码 |
| Agent 查询对象 | 该批次该品类的品质档案，而非某一颗果的独立档案 |
| 与订单关系 | **多对多**：一码对应多笔订单，一笔订单也可能含多码（多品类） |

### 1.4 产品目标

| 阶段 | 目标 |
|------|------|
| MVP（8 周） | 跑通咨询 → 批次溯源查询 → 购买引导 → 购后问答主链路 |
| 成长期 | 提升转化率与复购率，沉淀用户偏好档案 |
| 成熟期 | 成为品牌信任入口，支撑溢价与会员体系 |

### 1.5 成功指标（MVP）

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 咨询完成率 | ≥ 70% | 用户发起咨询后获得明确结论的比例 |
| 溯源查询成功率 | ≥ 95% | 有效码查询成功返回完整批次信息 |
| 咨询→购买转化率 | ≥ 8% | 有购买意向用户中完成下单比例 |
| 7 日复访率 | ≥ 25% | 用户 7 天内再次使用 Agent |
| 购后满意度 | ≥ 4.2/5 | 到货/开果后评价 |

## 2. 目标用户

### 2.1 核心用户画像

| 画像 | 特征 | 核心诉求 |
|------|------|----------|
| 新手尝鲜者 | 第一次买或很少买榴莲 | 品种怎么选、会不会踩坑 |
| 品质型消费者 | 有预算，追求稳定品质 | 批次可信、品质稳定、成熟度合适 |
| 送礼/聚会用户 | 偶尔高频、注重体面 | 规格合适、有面子、可追溯 |
| 老饕复购用户 | 有固定偏好 | 快速找到熟悉批次/果园、新批次提醒 |

### 2.2 暂不覆盖（二期）

- 果园/批发商 B 端采购
- 跨境大宗贸易
- 纯娱乐向榴莲内容社区

## 3. 核心用户旅程

```
咨询选购 → 扫批次码验真 → 下单购买 → 物流跟踪 → 到货开果 → 评价/售后 → 复购推荐
    ↑                                                                    |
    └──────────────────── 个人偏好档案沉淀 ←──────────────────────────────┘
```

### 3.1 典型场景

**场景 A：不会挑，想直接买**
> 用户：「300 左右，要甜一点、气味不要太重，推荐一下。」
> Agent：推荐在售 SKU → 展示该 SKU 关联的批次溯源摘要 → 引导下单。

**场景 B：收到货/在门店，想验这批货靠不靠谱**
> 用户：扫描包装上的溯源码。
> Agent：返回该批次该品类的档案（品种、产地、采摘/入库时间、品质等级、批次验真状态）。

**场景 C：到货后不确定能不能开**
> 用户：上传照片 + 提供批次溯源码（或订单号）。
> Agent：结合该批次入库成熟度区间与当前时间，给出开果建议；照片辅助判断单颗果状态。

**场景 D：不满意要售后**
> 用户：「过生了，和描述不符。」
> Agent：通过 **订单号 + 批次溯源码** 定位购买记录 → 按规则引导售后（因一码多订单，不能仅凭码唯一定位）。

### 5.2 溯源验真模块（一批一品类一码）

> **核心原则**：溯源码对应「某批次 + 某品类」的品质档案，而非单颗果。Agent 回答的是「这批货」的来源与品质可信度；涉及单颗果差异（果重、熟度）时，需结合商品规格说明或识果能力补充，不得假装码能定位到具体某一颗。

#### 批次溯源数据模型（Agent 依赖字段）

| 字段 | 必填 | 说明 | Agent 用途 |
|------|------|------|------------|
| trace_code | 是 | 批次品类溯源码（唯一） | 查询主键 |
| batch_id | 是 | 批次 ID | 内部关联、运营追溯 |
| batch_name | 否 | 批次名称/编号（如「6月8日马来入库」） | 用户可读展示 |
| variety | 是 | 品类/品种（如猫山王、金枕） | 验真、推荐验证 |
| grade | 否 | 等级（A/B 等） | 品质说明、商品匹配 |
| origin | 是 | 产地/果园 | 信任背书 |
| pick_date | 是 | 采摘日期（批次级） | 新鲜度说明 |
| stock_in_date | 是 | 入库日期（批次级） | 成熟度推算 |
| weight_range | 否 | 规格区间（如 3–4 斤/颗） | 替代单果重量 |
| ripeness_range | 否 | 批次成熟度区间（如 75%–85%） | 开果建议基准 |
| qty_in_batch | 否 | 该品类本批次入库数量 | 规模背书（可选展示） |
| inspection_result | 否 | 批次质检结论 | 品质信任 |
| cold_chain_status | 否 | 冷链状态 | 品质保障说明 |
| logistics_nodes | 否 | 批次物流节点时间线 | 在途状态展示 |
| batch_status | 是 | 在库/在售/售罄/已下架 | 状态判断 |
| listing_ids | 否 | 关联在售商品 SKU 列表 | 购买跳转 |
| qr_valid | 是 | 码是否有效 | 防伪结果 |
| valid_from / valid_to | 否 | 码有效期 | 过期提示 |

### 5.7 Agent 能力与安全

#### P0

| 功能 ID | 功能名称 | 说明 | 验收标准 |

| G-01 | 工具调用编排 | Agent 可调用溯源、商品、订单、知识库等工具 | 工具调用成功率 ≥98% |

## 11. 风险与依赖

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 用户误以为一果一码 | 信任受损、售后纠纷 | 扫码页 + Agent 统一话术；包装印刷明显标注 |
| 溯源数据不完整 | 验真体验差 | MVP 前补齐 P0 必填字段 |
| 在售库存不同步 | 推荐失效 | 商品接口实时查询，禁止 Agent 编造库存 |
| 过度推销引起反感 | 用户流失 | 先给建议再推荐；单次推荐 ≤3 个 |
| 批次内个体差异 | 成熟度/口感投诉 | 对外说明自然差异；P1 上线识果；售后规则前置 |
| 一码无法唯一定位订单 | 售后链路断裂 | 售后以订单号为主、批次码为辅；登录用户展示关联订单列表 |
| 批次码与商品 SKU 未绑定 | 扫码后无法购买 | 上架时完成 SKU ↔ 批次码绑定 |

### 11.1 外部依赖

- 溯源系统：批次品类溯源码查询 API
- 商城系统：商品、库存、价格、下单链接、SKU-批次关联
- 订单系统：订单查询（含批次码字段）、售后工单（P1）
- 用户系统：登录态、用户 ID

## 12. 附录：对话输出规范（P0）

每次咨询回复建议包含：

```
【结论】可以买 / 再等等 / 不建议 / 需扫码验批次

【理由】
1. ...
2. ...
3. ...

【下一步】
- 扫批次溯源码 / 查看推荐商品 / 到货后开果 / 售后请提供订单号

【可选卡片】
- 批次溯源卡片 / 商品推荐卡片
```

扫码验真回复补充：

```
【验真结论】该批次溯源码有效 / 无效

【批次信息】品种、产地、入库日期、等级、成熟度区间

【说明】本码代表该批次该品类，同码榴莲品质一致；单颗果熟度可能有自然差异。
```

## 14. 附录：v1.0 → v1.1 变更摘要

| 变更项 | v1.0（一果一码） | v1.1（一批一品类一码） |
|--------|------------------|------------------------|
| 码粒度 | 每颗果独立码 | 同批次同品类共用一码 |
| 查询对象 | 单果档案 | 批次品类档案 |
| 售后定位 | 溯源码可关联唯一订单 | **订单号为主**，溯源码辅助 |
| 食用建议 | 基于单果成熟度 | 基于批次成熟度区间 + 个体差异说明 |
| 新增能力 | — | 码粒度说明（T-07）、商品关联批次（P-06）、批次差异说明（A-05）、话术约束（G-06） |
| 识果定位 | 码即单果 | 识果为个体判断，需结合批次区间（P1） |
